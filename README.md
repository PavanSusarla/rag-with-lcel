
# 🦜🔗 RAG with LCEL (LangChain Expression Language)

This repo demonstrates how to build a **simple Retrieval-Augmented Generation (RAG) pipeline** using **LangChain Expression Language (LCEL)**.

## 🚀 Features
- Uses **LCEL** for declarative pipeline building
- Integrates retriever + prompt + LLM in just a few lines
- Supports streaming, async, and batching

## 📂 Repo Structure
- `rag_lcel_example.py` → RAG pipeline code
- `requirements.txt` → Python dependencies

## ⚡ Quickstart
```bash
git clone https://github.com/<your-username>/rag-with-lcel.git
cd rag-with-lcel
pip install -r requirements.txt
python rag_lcel_example.py
